💡 One feature that could make LocalWork stand out

Instead of only showing "On Job", create a Worker Availability System.

The badge changes automatically:

🟢 Available – Ready for work.
🟡 Interview Scheduled – Has an upcoming interview.
🔵 Working – Currently hired for an active job.
🟣 Available Soon – Current job ends within 3 days.
⚫ Offline – User disabled availability.

Businesses could filter workers by these statuses, making hiring much faster while giving workers clear visibility of their availability. It reinforces the idea that LocalWork is a live local workforce platform, not just another job listing app.
